# HR Analytics Dashboard 

##  Problem Statement
Why are employees leaving the company?

##  Project Overview
Built an interactive HR Analytics Dashboard in Power BI 
analyzing 1,470 employee records to understand 
employee attrition patterns.

##  Key Findings
-  16.1% attrition rate — 237/1,470 employees left
-  71% exits from below ₹5K salary slab (168/237)
-  Age group 26–35 highest attrition — 116 employees
-  Laboratory Technicians (62) most at-risk role
-  Sales Executives (57) second highest attrition
-  Employees with 0–1 year tenure leave the most

##  Tools Used
- Power BI
- DAX Measures
- Microsoft Excel
